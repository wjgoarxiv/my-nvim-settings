# Tokyo Night Day flavor for Yazi

Light-mode counterpart of the bundled `tokyo-night` flavor. The palette is the
Tokyonight Day theme shipped by [folke/tokyonight.nvim](https://github.com/folke/tokyonight.nvim)
(`extras/yazi/tokyonight_day.toml`), packaged as a Yazi flavor so it can be selected via
`[flavor] light = "tokyo-day"` in `theme.toml`.
